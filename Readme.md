🚀 DevConf2026

DevConf2026 is a modern and responsive conference landing page built using HTML5 and CSS3. The project showcases a fictional developer conference with a clean layout, engaging sections, and a user-friendly design.

✨ Features

* Responsive design
* Modern hero section
* Navigation bar
* Speakers section
* Event schedule
* Conference tracks
* Venue information
* Call-to-action (Register Now)
* Clean and well-structured code

🛠️ Technologies Used

* HTML5
* CSS3

🎯 Project Purpose

This project was created as part of my frontend development learning journey. It helped me practice semantic HTML, responsive layouts, CSS styling, and building modern landing pages from scratch.

📂 Project Structure

* index.html
* style.css
* images/
